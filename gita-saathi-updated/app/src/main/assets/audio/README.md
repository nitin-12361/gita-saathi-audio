# Spiritual background ambience (optional, one file for the whole app)

Drop one file here named:

    background_ambient.mp3

This plays quietly on a loop (18% volume) underneath every chant + narration, to
give the "spiritual background" feel you asked for. Since it's one shared ambient
bed rather than per-verse music, it costs nothing and is simple to source — search
for a royalty-free "temple bells", "tanpura drone", or "meditation ambience" loop
(Pixabay Audio and Free Music Archive both have good free/CC0 options).

If this file isn't present, playback just has no background bed — nothing breaks.
